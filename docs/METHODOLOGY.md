# Methodology

## Goal

Build a reproducible, source-aligned graph of Buddhist textual witnesses without collapsing distinct recensions into a fictitious single "original".

## Evidence layers

1. **Physical manuscript or inscription**
2. **Critical/diplomatic edition**
3. **Canonical translation witness**
4. **Parallel identification**
5. **Reconstruction or back-translation**

Lower-numbered layers should never be silently replaced by higher-numbered interpretive layers.

## Required distinctions

Keep these dates separate:
- estimated composition date
- manuscript date
- translation date
- catalog attestation date
- modern edition date

Keep these relations separate:
- exact textual parallel
- partial parallel
- shared passage
- doctrinal parallel
- probable common ancestor
- thematic similarity only

## Confidence

Use:
- `high`: supported by direct textual correspondence and/or established scholarship
- `medium`: persuasive but not decisive correspondence
- `low`: exploratory hypothesis
- `unknown`: insufficient evidence

## Reconstruction rule

A reconstructed Sanskrit title or passage must be labeled `reconstructed`. It must never be presented as an attested Indic witness.

## Normalization

Normalized searchable text is useful, but original readings must remain recoverable. Do not overwrite source orthography, segmentation, damaged markers, supplied restorations, or editorial uncertainty.
