# Generated research indexes

Files under this directory are reproducible derived metadata.

- `agama-segments/` is generated from the exact CBETA XML-P5 commit pinned by the repository.
- `crosswalks/first-20-resolved.json` is generated from the curated crosswalk benchmark plus the segment index.

Do not hand-edit generated files. Change the source configuration, scripts, source pins, or curated crosswalks and rebuild.
